# أقواس الشخصيات

## الدور

ترسم تحوّل المعتقد/القيمة عبر **قرارات** في مشاهد.

## أنواع

| النوع | المعنى |
|-------|--------|
| change | يتغيّر المعتقد الجوهري |
| fall | انحدار واعٍ أو عمى متزايد |
| revelation | انكشاف للقارئ/للذات |
| flat-impact | ثبات يغيّر العالم حوله |
| tragic-stasis | عجز عن التعلّم |

## الخطوات

1. اذكر المعتقد في البداية.  
2. حدّد 3–5 اختبارات ضغط (مشاهد).  
3. بيّن القرار في كل اختبار.  
4. صغ المعتقد في النهاية (أو عجزه).  

## ما لا تفعله

- لا «أدرك فجأة» بلا مقدمات سلوكية.
