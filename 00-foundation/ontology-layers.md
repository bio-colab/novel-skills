# الطبقات الذرّية — مرجع سريع

للاستخدام عند تصميم المهارات ومراجعتها.

## 1. المادة → الشكل

| عربي | إنجليزي | روسي/سرديات | معنى تشغيلي |
|------|---------|-------------|-------------|
| مادة / أحداث العالم | Story / Fabula | фабула | ما حدث زمنيًا في العالم |
| حبكة / ترتيب فني | Plot / Syuzhet | сюжет | كيف يُقدَّم ولماذا بهذا الترتيب |
| خطاب سردي | Narrative discourse | — | صوت، زمن، مسافة، تبئير |

## 2. الشخصية

| حقل | سؤال التصنيع |
|-----|----------------|
| Want | ماذا تريد الآن علنًا؟ |
| Need | ماذا تحتاج حقًا؟ |
| Ghost | أي جرح يحرّكها؟ |
| Fear | ما الذي تتجنّبه بأي ثمن؟ |
| Value | أي قيمة مستعدة أن تخسر من أجلها؟ |
| Contradiction | أين تكذب على نفسها؟ |
| Arc | كيف تختلف في النهاية — أو لماذا لا تختلف؟ |

## 3. المشهد (حد أدنى إلزامي)

1. هدف  
2. عائق  
3. فعل  
4. تحوّل  
5. باطن تحت الظاهر  

## 4. المعنى

- الثيم = **سؤال** يُختبر بالفعل  
- الرمز = علامة تتكرر وتتغيّر  
- السخرية = فجوة معرفة أو قصد  
- الأثر = ما يبقى في القارئ (تعرّف، غرابة، شفقة، رعب أخلاقي…)

## 5. التداخل

```
Character ↔ Character  = سلطة / حاجة / سر / دين عاطفي
Character ↔ Environment = ضغط خيارات + تغيير متبادل
Character ↔ Self        = قيم متصارعة
```

## 6. عدسات التقليد (اختصارات)

| عدسة | كلمة سر |
|------|---------|
| كلاسيكي | وحدة فعل + تحوّل + تعرّف |
| إنجليزي | سببية + استدارة + سبتيكست |
| روسي | تعدد أصوات + تغريب + فابيولا/سيوجيت |
| عربي | إطار حكائي + مكان اجتماعي–تاريخي + سلطة السرد |
