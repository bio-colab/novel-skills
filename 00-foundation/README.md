# قاعدة فنّ كتابة الرواية — أساس مهارات الذكاء الاصطناعي

> وثيقة مراجعة أولى (v0.1)  
> الهدف: تأسيس **قاعدة معرفية ومعمارية** لبناء مهارات AI متخصصة في كتابة الرواية، قبل تصميم المهارات نفسها.

---

## 1. لماذا هذه القاعدة؟

كتابة الرواية ليست «وصفة» واحدة، بل **نظام طبقات** يتقاطع فيه:

| الطبقة | السؤال الجوهري |
|--------|----------------|
| السيناريو / المادة | ماذا يحدث في العالم؟ |
| الحبكة | لماذا يحدث، وبأي ترتيب يُروى؟ |
| الشخصيات | من يريد ماذا، ولماذا يفشل أو يتغيّر؟ |
| التداخل | كيف تتصادم الذوات مع بعضها ومع المكان؟ |
| الرسائل المبطنة | ماذا يُقال دون أن يُقال؟ |
| السيميائيات / الشعرية | كيف تُنتج العلامات معنى وإحساسًا؟ |

كل مهارة AI لاحقة يجب أن تخدم طبقة واحدة بوضوح، ثم تتصل بالطبقات الأخرى عبر **عقود** (interfaces) مشتركة: رغبة، عائق، قيمة على المحك، صوت، فضاء، أثر.

## 2. خريطة التقاليد الأربعة (ملخّص بحثي)

### 2.1 اللاتيني / الكلاسيكي (جذور البنية والأخلاق الفنية)

| المصدر | الإسهام للرواية (استعارة / تطبيق) |
|--------|-----------------------------------|
| **أرسطو — فن الشعر** | الوحدة، الحبكة كترتيب للأفعال، التحوّل (peripeteia)، التعرف (anagnorisis)، الخطأ المأساوي (hamartia)، التطهير (catharsis). الحبكة «روح» العمل. |
| **أرسطو — الخطابة** | Ethos / Pathos / Logos: بناء مصداقية الصوت، إثارة العاطفة، منطق الإقناع — أساس **صوت الراوي** و**الإقناع الدرامي**. |
| **هوراس — فن الشعر (Ars Poetica)** | *utile dulci* (الإفادة والمتعة)، ملاءمة الشخصية للفعل (decorum)، وحدة النبرة، «ابدأ من الوسط» (in medias res). |
| **شيشرون / كوينتيليان** | بناء الشخصية الخطابية (ethos)، التكيّف مع الجمهور، الاتساق الأخلاقي للصوت — ينعكس على **صوت الراوي** و**قناع الشخصية**. |
| **الملاحم والرومنس اللاتيني/الأوروبي** | رحلة البطل، التجربة، العودة؛ نواة ما سيُسمّى لاحقًا «رحلة البطل» و«الرواية الرومنسية». |

**مبدأ مستخلص:** الفعل المنظم + ملاءمة الشخصية + أثر عاطفي–معرفي على المتلقي.

---

### 2.2 الإنجليزي / الأنجلوسكسوني (حرفة الرواية الحديثة)

| المصدر | الإسهام |
|--------|---------|
| **E. M. Forster — Aspects of the Novel** | Story vs Plot (تتابع زمني vs سببية)، شخصيات **مسطحة / مستديرة**، اختبار الاستدارة: «هل تفاجئ بإقناع؟»، Fantasy / Prophecy / Pattern / Rhythm. |
| **Percy Lubbock / Henry James** | «نقطة الرؤية»، الرواية كعرض (showing) لا تقرير (telling)، الوعي كميدان. |
| **Wayne Booth — The Rhetoric of Fiction** | الراوي الموثوق / غير الموثوق، المسافة البلاغية، المؤلف الضمني. |
| **John Gardner — The Art of Fiction** | الحلم الخيالي المستمر (vivid continuous dream)، التفاصيل الحسية، الوضوح الأخلاقي للفنان. |
| **James Wood — How Fiction Works** | الأسلوب غير المباشر الحر (free indirect style)، التفاصيل «الواقعية»، وعي الشخصية كمحرّك. |
| **Robert McKee — Story** (سينمائي لكنه مركزي للحرفة) | رغبة واعية/لاواعية، مستويات الصراع (داخلي–شخصي–خارجي)، **لا مشهد بلا تحوّل**، النص vs **السبتكست**. |
| **Vladimir Propp** (أثر عالمي على الحرفة الإنجليزية) | وظائف الحكاية، أنماط الأدوار — مفيد كـ **قوالب قابلة للكسر** لا كقيود. |
| **Joseph Campbell / Vogler** | رحلة البطل — أداة تخطيط، لا دينًا. |
| **Freytag / ثلاثي/خماسي البنية** | تصاعد–ذروة–هبوط؛ نقاط التحول؛ مفيد للرواية التجارية والسيناريو. |

**مبدأ مستخلص:** السببية + الوعي + تحوّل المشهد + السبتكست.

---

### 2.3 الروسي (وعي، تعدد أصوات، شكل)

| المصدر | الإسهام |
|--------|---------|
| **الشكلانيون الروس (شكلوفسكي وآخرون)** | *Fabula* (المادة الزمنية الخام) vs *Syuzhet* (الترتيب الفني)، **التغريب** (остранение / defamiliarization): جعل المألوف غريبًا ليعاد إدراكه. |
| **فلاديمير بروب** | مورفولوجيا الحكاية الشعبية: 31 وظيفة، أدوار ثابتة — نموذج بنيوي للأفعال. |
| **ميخائيل باختين** | **تعدد الأصوات (polyphony)**، الحوارية (dialogism)، الخطاب الروائي كحقل لغات اجتماعية، الكرنفال، عدم اندماج وعي المؤلف بوعي الشخصيات. |
| **دوستويفسكي** (كممارسة نظرية عند باختين) | شخصيات = ذوات كاملة ذات خطاب مستقل، لا دمى أيديولوجية؛ الفكرة «تعيش» داخل الشخصية. |
| **تولستوي** | الواقعية النفسية–الاجتماعية، الزمن الطويل، البيئة كقوة تشكيل، «الديالكتيك الروحي» للشخصية. |
| **تشيخوف** (قصة/مسرح لكنه أساس الرواية الحديثة) | التلميح، النهاية المفتوحة، التفاصيل الكاشفة، ما لا يُقال. |

**مبدأ مستخلص:** ترتيب فني للمادة + تعدد وعي متكافئ + تغريب الإدراك.

---

### 2.4 العربي (تراث سردي + رواية حديثة)

| المصدر / التيار | الإسهام |
|-----------------|---------|
| **ألف ليلة وليلة** | السرد الإطاري، الحكاية داخل الحكاية، التشويق كبقاء، التحويل الأخلاقي بالمحكي (شهرزاد ↔ شهريار)، العجائبي، الراوي المتعدد المستويات. |
| **المقامات** | الراوي والبطل المخادع، اللغة كعرض، الحيلة والسخرية الاجتماعية. |
| **السيرة الشعبية** | البطولة، الدورات، الجماعة كبطل، الزمن الدوري. |
| **نجيب محفوظ** | المدينة كشخصية، الطبقات الاجتماعية، الواقعية + الرمز + الحارة كعالم مصغّر، تطور طويل الأمد للشخصيات. |
| **الطيب صالح — موسم الهجرة إلى الشمال** | صدام الحضارات داخل الذات، الراوي الملتبس، الاستعمار كبيئة نفسية. |
| **عبد الرحمن منيف — مدن الملح** | المكان/النفط/التحوّل التاريخي كمحرّك، الملحمة الروائية الحديثة. |
| **غسان كنفاني، حنا مينه، جبرا، صنع الله إبراهيم، هدى بركات…** | تيارات: المقاومة، البحر/الطبقة، المنفى، التجريب، الحرب والجسد. |
| **نقد عربي حديث** (فيصل درّاج، عبد الله إبراهيم، نبيل سليمان، يمنى العيد…) | سرديات عربية، الراوي، الزمن، الهوية، الرواية كشكل وعي تاريخي. |

**مبدأ مستخلص:** الحكاية كبقاء وتأويل + المكان الاجتماعي–التاريخي + تعدد مستويات الراوي + الرمز دون قتل الواقع.

## 3. النموذج الطبقي الموحّد (Core Ontology)

هذه «الأونتولوجيا» المشتركة التي ستُبنى عليها كل المهارات.

```
WORLD (العالم)
 ├── Time regimes          (أنظمة الزمن: خطي، دائري، مكسور، أسطوري)
 ├── Space / Environment   (المكان كقوة فاعلة لا ديكور)
 ├── Social field          (طبقات، سلطة، لغة، تابوهات)
 └── Symbolic system       (رموز، طقوس، أساطير داخل العمل)

STORY MATERIAL (المادة / Fabula)
 ├── Events                (أحداث ممكنة)
 ├── Facts of the world    (حقائق العالم القصصي)
 └── Backstory reservoir   (خزان الماضي)

NARRATIVE FORM (الشكل / Syuzhet + Discourse)
 ├── Plot architecture     (بنى الحبكة)
 ├── Order / Duration / Frequency   (جينيت)
 ├── Mood & Voice          (مسافة، تبئير، صوت)
 └── Style & Rhythm        (نبرة، إيقاع، تغريب)

CHARACTERS (الذوات)
 ├── Desire (conscious / unconscious)
 ├── Need vs Want
 ├── Wound / Ghost          (الجرح / الشبح الماضي)
 ├── Values & Contradiction
 ├── Voice / Idiolect
 ├── Arc type               (تغيير / ثبات مأساوي / انحدار)
 └── Relationships graph   (شبكة علاقات ديناميكية)

SCENE (وحدة التنفيذ)
 ├── Goal
 ├── Conflict (inner / relational / environmental)
 ├── Turn (value change)
 ├── Text vs Subtext
 └── Aftermath / New state

MEANING LAYER (طبقة المعنى)
 ├── Theme (as dramatic question, not slogan)
 ├── Motifs & symbols
 ├── Irony (dramatic / verbal / situational)
 └── Reader effect (catharsis, estrangement, recognition…)
```

## 4. تفصيل الطبقات المطلوبة منك

### 4.1 من السيناريو إلى الحبكة

| المفهوم | التعريف العملي | تقاليد داعمة |
|---------|----------------|--------------|
| **سيناريو / مادة** | مجموع ما «حدث» أو يمكن أن يحدث في العالم، مرتبًا زمنيًا | Fabula (شكلانية)، Story (Forster) |
| **حبكة** | ترتيب سببي–درامي يُقدَّم للقارئ، يخلق سؤالًا ويؤجّل الإجابة | Plot (Forster)، Syuzhet، أرسطو، McKee |
| **حدث محرّك** | كسر التوازن الذي يطلق السعي | McKee Inciting Incident، أرسطو بداية |
| **نقاط تحوّل** | لحظات لا عودة؛ تغيّر شروط اللعبة | Freytag، بنية ثلاثية/خماسية |
| **ذروة** | أقصى ضغط حيث تتصارع قيم الشخصية علنًا | أرسطو، McKee |
| **حل / أثر** | ليس «نهاية الأحداث» فقط بل **معنى جديد** للعالم الداخلي/الخارجي | Catharsis، التعرف |

**قواعد تصميم للحرفة:**

1. كل حدث حبكي يُجيب: *بسبب ماذا؟ فماذا تغيّر؟*
2. الحبكة = ضغط متصاعد على **قيمة** (حب، كرامة، حرية، انتماء…).
3. يمكن كسر الخطية (فلاش باك، توازٍ، سرد إطاري — تراث *الليالي*) بشرط وضوح **العقد مع القارئ**.

---

### 4.2 أنماط الشخصيات (Character Patterns)

ليست قوالب جامدة، بل **محاور تصميم**:

| النمط / المحور | الوصف | أمثلة مرجعية |
|----------------|-------|--------------|
| **مستديرة / مسطحة** | تعدد سمات + قدرة على المفاجأة المقنعة / سمة مهيمنة | Forster؛ ديكنز (مسطح فذ) vs أوستن (استدارة) |
| **بطل ساعٍ** | رغبة واضحة + عوائق متصاعدة | الملحمة، الرواية الواقعية |
| **بطل ملتبس / مضاد** | قيم متضاربة؛ القارئ يتعاطف دون أن يبرّر | دوستويفسكي، موسم الهجرة |
| **شخصية فكرة (voice-idea)** | الوعي = موقف فلسفي حيّ لا خطاب المؤلف | باختين / الإخوة كارامازوف |
| **مرآة / قرين / خصم** | يكشف البطل بالانعكاس أو التصادم | الثنائيات الروائية |
| **جماعة / مدينة كفاعل** | الحارة، القبيلة، الطبقة | محفوظ، منيف |
| **راوٍ–شخصية** | السرد جزء من دراما المصداقية | Booth، السرد العربي الحديث |

**بطاقة شخصية معيارية (لأي مهارة AI لاحقة):**

```yaml
id: char_01
name: 
role_in_plot: # protagonist | antagonist | catalyst | foil | witness
surface_want: 
deep_need: 
ghost_wound: 
core_fear: 
core_value: 
contradiction: # ما يؤمن به vs ما يفعله
voice_traits: # معجم، إيقاع، محظورات لغوية
arc: # change | fall | flat-impact | revelation
relationship_edges:
  - target: char_02
    type: love|power|debt|rivalry|secret
    current_tension: 0-10
environment_bond: # كيف يشكّله المكان / وكيف يغيّره
```

### 4.3 تطور الشخصيات وتداخلها مع بعضها ومع البيئة

**ثلاثة محاور للتطور:**

1. **داخلي:** معتقد → أزمة → إعادة تأويل الذات  
2. **علائقي:** كل علاقة = نظام قوى (سلطة، حاجة، سر، دين) يتغيّر بمشاهد  
3. **بيئي:** المكان ليس خلفية؛ يمارس **ضغطًا** (فقر، حرب، مدينة نفطية، منفى، حارة، بحر…)

**مصفوفة التداخل (تُحدَّث مع كل فصل/مشهد):**

| | شخصية أ | شخصية ب | البيئة |
|--|---------|---------|--------|
| **أ** | صراع داخلي | رغبة/خوف مشترك أو متعارض | ما يأخذه أ من المكان / ما يفرضه المكان |
| **ب** | — | صراع داخلي | … |
| **البيئة** | تغيّر سببه أ | تغيّر سببه ب | تحوّل المكان نفسه (زمن تاريخي) |

**قواعد:**

- لا «تطور» بإعلان؛ التطور = **قرارات تحت ضغط**.
- البيئة الجيدة تُغيّر **خيارات** الشخصيات لا وصفها فقط.
- تداخل الشخصيات عند باختين: لا يبتلع صوتُ المؤلف أصواتَهم؛ الخلاف يبقى حيًّا.

### 4.4 الرسائل المبطنة (Subtext)

| النوع | التعريف | أداة الكتابة |
|-------|---------|--------------|
| **سبتكست حواري** | المعنى تحت الكلام | ما يُراد ≠ ما يُقال؛ الصمت، التحويل، السخرية |
| **سبتكست مشهدي** | المشهد «عن» قيمة غير معلنة | McKee: إن كان المشهد يقول ما يعنيه حرفيًا فهو ضعيف |
| **مفارقة درامية** | القارئ يعرف ما تجهله الشخصية | أرسطو / المسرح → الرواية |
| **رمز / موتيف** | تكرار علامة تتغيّر دلالتها | واقعية محفوظ الرمزية، تفاصيل تشيخوف |
| **أسلوب غير مباشر حر** | وعي الشخصية يتسرّب للنص دون «فكّر» | James Wood / Flaubert |
| **راوٍ غير موثوق** | الفجوة بين الرواية والحقيقة | Booth |
| **الثيم كسؤال** | لا شعار أخلاقي؛ سؤال يُختبر دراميًا | «هل يمكن الخلاص بالكذب؟» لا «الكذب سيء» |

**تمرين مهاري أساسي:**  
اكتب عمودَين لكل مشهد: *نص ظاهر* | *حقيقة المشهد*.

### 4.5 السيميائيات والشعرية (Poetics & Semiotics)

| المفهوم | التطبيق في كتابة الرواية |
|---------|---------------------------|
| **علامة** | شيء يحيل لشيء آخر داخل نظام العمل (باب، نهر، اسم، رائحة) |
| **موتيف** | علامة متكررة تتراكم / تنقلب |
| **حقل دلالي** | شبكة مفردات تبني عالمًا (مقدّس/مدنّس، يابس/رطب…) |
| **التغريب** | كسر آلية الإدراك الآلي (شكلوفسكي) |
| **الإيقاع** | طول الجمل، تكرار المشاهد، صمت الفصول (Forster: Rhythm) |
| **المسافة السردية** | قرب/بعد عن وعي الشخصية (Genette: Mood) |
| **التبئير** | من يرى؟ (صفر / داخلي / خارجي) |
| **الصوت** | من يتكلم؟ متى؟ بأي سلطة؟ |
| **العجائبي / الغرائبي** | تراث الليالي + Todorov: تردد بين التفسير الطبيعي والخارق |

**مبدأ:** الشعرية ليست زخرفة؛ هي **إدارة إدراك القارئ**.

## 5. أدوات سردية عابرة للتقاليد (Toolbox)

### 5.1 الزمن (Genette + تراث)

- **Order:** استرجاع، استباق، سرد متوازٍ، إطار (شهرزاد)  
- **Duration:** مشهد / تلخيص / حذف / وقفة وصفية  
- **Frequency:** يُروى مرة / يتكرر سردًا / حدث متكرر يُروى مرة  

### 5.2 الصراع (McKee levels)

1. داخلي (قيم متضاربة)  
2. شخصي (علاقات)  
3. خارجي / بيئي / مؤسسي  

### 5.3 المشهد كوحدة ذرية

```
Scene:
  POV character:
  Location + sensory pressure:
  Entering value state: (+/-)
  Goal:
  Obstacle:
  Strategy (what they try):
  Turn (what changes):
  Exiting value state:
  Subtext:
  Plot consequence:
  Character consequence:
  Motif/image planted or paid off:
```

### 5.4 بُنى حبكة شائعة (اختيارية، قابلة للمزج)

| البنية | متى تُستخدم |
|--------|-------------|
| ثلاثية / خماسية كلاسيكية | روايات سعي واضح |
| رحلة البطل | تحوّل عبر عتبات |
| متعدد الخطوط / متعدد الأصوات | مجتمع، ملحمة عائلية، باختينية |
| إطاري / حكايات متداخلة | تراث عربي، رواية عن الحكي نفسه |
| تحرّي / لغز | كشف تدريجي |
| دائري / أوديسي | العودة مع اختلاف الوعي |
| تشظّي حداثي | صدمة، ذاكرة، حرب |

### 6.1 مبادئ تصميم كل مهارة (Skill Contract)

كل مهارة يجب أن تصرّح:

1. **المدخلات** (Input schema)  
2. **المخرجات** (Output schema)  
3. **قيود الجودة** (مثلاً: لا حوار on-the-nose؛ كل مشهد يُحوّل قيمة)  
4. **التقاليد المرجعية** التي تستند إليها  
5. **ما لا تفعله** (حدود)  
6. **روابط** لمهارات أخرى (upstream / downstream)

### 6.2 معيار جودة موحّد (Definition of Done لمشهد/فصل)

- [ ] رغبة شخصية واضحة في المشهد  
- [ ] عائق حقيقي (داخلي أو خارجي)  
- [ ] تحوّل في قيمة أو علاقة أو معلومة  
- [ ] سبتيكست أو توتر بين الظاهر والباطن  
- [ ] البيئة تفعل شيئًا (تضغط / تُغري / تمنع / تشهد)  
- [ ] صوت متسق مع بطاقة الشخصية  
- [ ] الثيم يُختبر بالفعل لا بالخطبة  
- [ ] ارتباط سببي بما سبق وما يلي

## 8. مخاطر يجب تجنّبها في مهارات AI

| الخطر | العلاج في التصميم |
|-------|-------------------|
| قوالب هوليوود تُفرَّغ على كل رواية | البنى **اختيارية**؛ العدسات التراثية مفعّلة |
| شخصيات «ملفّات سمات» بلا تناقض حي | فرض `contradiction` + قرارات تحت ضغط |
| حبكة أحداث بلا سببية | ربط كل مشهد بـ because / therefore / but |
| شرح الثيم للقارئ | الثيم = سؤال درامي + سبتيكست |
| بيئة وصف سياحي | المكان يغيّر الخيارات |
| صوت واحد يبتلع الجميع | اختبار باختيني: هل لكل ذات خطاب مستقل؟ |
| تغريب زائد يقتل الوضوح | Gardner: الحلم المستمر؛ التغريب بخدمة الإدراك لا الإبهام |

## 10. أسئلة للمراجعة معك (نحدد خطوتنا التالية)

1. **نطاق المهارات:** هل تريد حزمة «كاتب روائي كامل» أم نبدأ بـ **MVP**: (شخصيات + حبكة + مشهد)؟  
2. **اللغة الأساسية للمهارات:** عربية فقط، أم عربية/إنجليزية مزدوجة للمصطلح؟  
3. **نوع الروايات المستهدفة:** واقعية اجتماعية، تاريخية، عجائبية، نفسية، بوليسية، أم عامة؟  
4. **درجة الصرامة البنيوية:** دليل مرن (عدسات) أم pipeline إلزامي خطوة بخطوة؟  
5. **هل نثبّت schemas تقنية** (YAML/JSON) منذ المرحلة 1 لسهولة استهلاك AI؟  
6. **عدسة التراث:** هل تُعطى الأولوية للعدسة العربية (ليالي + مدينة + تاريخ) كافتراضي؟

## 11. الخلاصة التنفيذية

- فن الرواية عبر التقاليد الأربعة يلتقي عند: **فعل سببي، ذوات متنازعة، شكل يُرتّب الإدراك، معنى تحت السطح، مكان يضغط**.  
- القاعدة هنا = **أونتولوجيا + طبقات + خريطة مهارات + معايير جودة + مسار**.  
- الخطوة التالية المنطقية بعد موافقتك: تثبيت `schemas` + كتابة `novel-craft-core` كمهارة أم، ثم أولى المهارات التنفيذية.
