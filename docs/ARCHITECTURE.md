# المعمارية — Novel Craft

## نظرة عامة

```
┌─────────────────────────────────────────────────────────┐
│  واجهة المستخدم (CLI / menu)                            │
│  novel_craft.cli · novel_craft.ui.menu                  │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────┐
│  أوضاع (Modes)                                          │
│  interview · write · analyze · critique · free          │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────┐
│  العقل المُدير (Orchestrator)                           │
│  يختار pipeline · يبني plan · يصدّر briefs · journal   │
└──────────────────────────┬──────────────────────────────┘
                           │
          ┌────────────────┼────────────────┐
          ▼                ▼                ▼
   skills_registry   ProjectStore      Agent (خارجي)
   + SKILL.md        projects/*        يقرأ brief
```

## طبقات المسؤولية

| طبقة | مسؤولية | ليست مسؤوليتها |
|------|---------|----------------|
| Python | ملفات، قوائم، خطط، سجل، مقابلة تفاعلية | كتابة أدب عالي الجودة آليًا بالكامل |
| Orchestrator | من/متى/كيف/ماذا | استبدال المهارات |
| Skills (SKILL.md) | تعليمات الوكيل الأدبية | منطق نظام الملفات |
| Foundation | نظرية ومراجع | تشغيل وقتي |
| Project tree | حالة عمل الكاتب | كود البرنامج |

## دورة حياة مشروع الكتابة

```
new → interview → vision
    → write_bootstrap (عالم، شخصيات، حبكة…)
    → write_draft_loop (مشاهد، حوار، سبتيكست…)
    → write_polish (شعرية، نقد)
    → exports / REPORT
```

## دورة التحليل

```
new(mode=analyze) → source.txt → analyze pipeline → analysis/*.md
```

## التوثيق الإلزامي

كل فعل مهم → `journal/events.jsonl`  
حقول: id, timestamp, actor, action, mode, summary, details, inputs, outputs, status
